# Book Scraper with Python and Playwright

A simple and efficient web scraping script built with Python and Playwright to extract book titles and prices from [Books to Scrape](https://books.toscrape.com/) and save them into a CSV file.

## 🚀 Features
* Automated browser navigation using **Playwright**.
* DOM element selection and data extraction (Title & Price).
* Structured data export to **CSV** format using Python's built-in `csv` module.

## 🛠️ Tech Stack
* **Python** (3.8+)
* **Playwright for Python**
* **CSV Module**
